# Benchmark Baselines

This directory stores benchmark baseline results in JSON format, generated by
`criterion` via `cargo bench`. Each file corresponds to a benchmark group.

## Updating Baselines

```bash
make bench-update-baseline
```

This runs all benchmarks and saves the results as the new baseline under
`target/criterion/`. The `scripts/bench-regression.sh` script compares
current runs against these baselines.

## Format

Criterion stores baselines in `target/criterion/<group>/<bench>/base/`.
The regression detection script reads `estimates.json` from each baseline
directory to extract the `point_estimate` (in nanoseconds).
